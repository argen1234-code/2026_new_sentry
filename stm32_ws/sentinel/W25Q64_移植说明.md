W25Q64 移植记录

模块归属 = `Devices/W25Q64` 设备级外部 Flash 封装。数据链路 = CubeMX 生成 `MX_OCTOSPI2_Init()` 完成 OSPI2 和引脚复用初始化 -> 应用调用 `OSPI_W25Qxx_Init()` 读取 JEDEC ID -> 擦除、写入、读取 API 通过 HAL OSPI 命令模式访问 W25Q64。

文件清单

| 文件 | 作用 |
| --- | --- |
| `Devices/W25Q64/inc/w25q64.h` | W25Q64 指令、容量、JEDEC ID、错误码和对外 API 声明 |
| `Devices/W25Q64/w25q64.c` | 基于 `hospi2` 的 OSPI 命令、自动轮询、擦写读和内存映射实现 |
| `Core/Src/octospi.c`、`Core/Inc/octospi.h` | CubeMX 生成的 OCTOSPI2 初始化、GPIO 复用、OSPIM Port1 映射 |
| `Core/Inc/stm32h7xx_hal_conf.h` | CubeMX 生成的 `HAL_OSPI_MODULE_ENABLED` 使能项 |
| `Core/Src/main.c` | W25Q64 初始化、32KB 擦写读校验、整片读速度测试 |
| `Core/Src/usart.c` | `printf` 经 USART1 输出测试结果，`fputc()` 调用 `HAL_UART_Transmit()` |
| `MDK-ARM/CtrlBoard-H7_W25Q64.uvprojx` | Keil 工程包含 `../Devices/W25Q64/inc`，并加入 `../Devices/W25Q64/w25q64.c` |

驱动接口和指令

| 接口或宏 | 含义 |
| --- | --- |
| `OSPI_W25Qxx_Init()` | 读取 `0x9F` JEDEC ID，匹配 `0xEF4017` 后返回 `OSPI_W25Qxx_OK` |
| `OSPI_W25Qxx_ReadID()` | 1 线指令、1 线数据读取 3 字节 JEDEC ID |
| `OSPI_W25Qxx_WriteEnable()` | 发送 `0x06`，随后自动轮询状态寄存器 1 的 WEL 位 |
| `OSPI_W25Qxx_AutoPollingMemReady()` | 自动轮询状态寄存器 1 的 BUSY 位，等待擦写读命令结束 |
| `OSPI_W25Qxx_SectorErase()` | `0x20`，4KB 扇区擦除 |
| `OSPI_W25Qxx_BlockErase_32K()` | `0x52`，32KB 块擦除 |
| `OSPI_W25Qxx_BlockErase_64K()` | `0xD8`，64KB 块擦除 |
| `OSPI_W25Qxx_ChipErase()` | `0xC7`，整片擦除，超时值 `100000U` ms |
| `OSPI_W25Qxx_WritePage()` | `0x32`，1 线指令、1 线地址、4 线数据页编程，单页 256 字节 |
| `OSPI_W25Qxx_WriteBuffer()` | 自动按 256 字节页切分后连续写入 |
| `OSPI_W25Qxx_ReadBuffer()` | `0xEB`，1 线指令、4 线地址、4 线数据快速读，DummyCycles = 6 |
| `OSPI_W25Qxx_MemoryMappedMode()` | `0xEB` 快速读配置进入内存映射，映射基址 `0x90000000` |

应用接入顺序

- 复制 `Devices/W25Q64/w25q64.c` 和 `Devices/W25Q64/inc/w25q64.h` 到目标工程同类设备目录。
- 在目标工程包含路径加入 `Devices/W25Q64/inc`，并把 `w25q64.c` 加入编译。
- 通过 CubeMX 配置 OCTOSPI2、GPIO、时钟、HAL OSPI 模块，再生成 `octospi.c/.h` 和 `stm32h7xx_hal_conf.h`。
- 在应用初始化阶段按 `HAL_Init()` -> `SystemClock_Config()` -> `MX_GPIO_Init()` -> `MX_OCTOSPI2_Init()` -> `OSPI_W25Qxx_Init()` 顺序执行。
- 量产应用调用擦除 API 后再调用写入 API；读取 API 可直接调用；内存映射 API 调用后通过 `0x90000000 + offset` 读取。
- 调试输出使用 USART1 时，初始化 `MX_USART1_UART_Init()`，并提供 `fputc()` 到 `HAL_UART_Transmit()` 的重定向。

移植核对点

- `w25q64.c` 默认引用外部句柄 `hospi2`，目标工程使用其他 OSPI 实例名时同步修改句柄引用或提供同名句柄。
- `W25Qxx_FlashSize = 0x800000`，`W25Qxx_PageSize = 256`，`W25Qxx_FLASH_ID = 0xEF4017`，目标芯片容量和 ID 变化时同步更新这些宏。
- 写入前先擦除目标区域，擦除地址按 4KB、32KB、64KB 边界规划。
- `OSPI_W25Qxx_ReadBuffer()` 和 `OSPI_W25Qxx_MemoryMappedMode()` 使用 `0xEB` 快速读，地址和数据均为 4 线，空周期为 6。
- `OSPI_W25Qxx_WritePage()` 单次最大写入 256 字节，`OSPI_W25Qxx_WriteBuffer()` 已按页切分。
- 当前测试代码使用 32KB 全局静态缓冲区，目标工程 RAM 布局需要容纳读写数组。
