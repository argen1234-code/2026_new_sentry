麦克纳姆底盘闭环与急停减速链路

适用工程配置：`User/APP/robot_param.h:64-69` 中 `ROBOT_TYPE = Engineer_robot`、`ROBOT_CHASSIS = Mecanum_wheel`、`ROBOT_GIMBAL = multi_axis_robotic_arm`、`ROBOT_BOARD = gimbal_board`，因此底盘入口使用 `User/chassis/Mecanum_chassis.c` 中的麦克纳姆轮实现。

核心数据结构：`chassis_move_t` 在 `User/APP/chassis_task.h:60-96` 定义，包含遥控器指针 `chassis_RC`、云台 yaw/pitch 电机指针、底盘 INS 角度指针、底盘模式 `chassis_mode`、上一次模式 `last_chassis_mode`、四个底盘电机数据、四个电机速度 PID、底盘 yaw 角度 PID、`vx/vy/wz` 实际速度、`vx_set/vy_set/wz_set` 目标速度、`chassis_yaw_set` 目标 yaw、`chassis_yaw` 实际 yaw、`slowmode` 慢速标志。

任务主链路：`chassis_task()` 在 `User/APP/chassis_task.c:129-173` 先延时 `CHASSIS_TASK_INIT_TIME = 357` ms，再执行 `chassis_init(&chassis_move)`，随后等待四个底盘电机和 DBUS 在线；循环周期为 `CHASSIS_CONTROL_TIME_MS = 2` ms，每周期顺序为 `chassis_set_mode()` → `chassis_mode_change_control_transit()` → `chassis_feedback_update()` → `chassis_set_contorl()` → `chassis_control_loop()` → `chassis_send_cmd()` → `osDelay(2)`。

初始化链路：`chassis_init()` 在 `User/chassis/Mecanum_chassis.c:32-92` 把底盘初始模式设为 `CHASSIS_VECTOR_RAW`，绑定遥控器数据、INS 欧拉角、云台 yaw/pitch 电机、四个底盘电机反馈；四个底盘电机速度环使用 `M3505_MOTOR_SPEED_PID_KP = 15000.0f`、`KI = 10.0f`、`KD = 0.0f`、最大输出 `16000.0f`、积分限幅 `2000.0f`；底盘 yaw 角度环使用 `CHASSIS_FOLLOW_GIMBAL_PID_KP = 10.0f`、`KI = 0.0f`、`KD = 0.1f`、最大输出 `6.0f`、积分限幅 `0.2f`；`vx/vy` 一阶滤波参数分别为 `CHASSIS_ACCEL_X_NUM = 0.1666666667f`、`CHASSIS_ACCEL_Y_NUM = 0.3333333333f`。

遥控输入定义：`User/ROBOT/Engineer.h:80-123` 中 `CHASSIS_X_CHANNEL = 1`、`CHASSIS_Y_CHANNEL = 0`、`CHASSIS_WZ_CHANNEL = 2`、`CHASSIS_MODE_CHANNEL = 0`、`CHASSIS_FOLLOW_CHANNEL = 1`；摇杆死区 `CHASSIS_RC_DEADLINE = 25`；`vx/vy` 摇杆灵敏度均为 `0.003f`，yaw 角度增量灵敏度为 `0.000005f`，直接角速度灵敏度为 `0.004f`；W/A/S/D 给平移命令，Q/E 给转向命令，Shift 进入慢速模式。

行为模式入口：`chassis_set_mode()` 在 `User/chassis/Mecanum_chassis.c:104-112` 调用 `chassis_behaviour_mode_set()`；`chassis_behaviour_mode_set()` 在 `User/APP/chassis_behaviour.c:320-407` 根据遥控拨杆和按键写入 `chassis_behaviour_mode`，并把行为模式映射到底盘控制模式。`CHASSIS_MODE_CHANNEL` 下档且 `CHASSIS_FOLLOW_CHANNEL` 下档时进入 `CHASSIS_ENGINEER_FOLLOW_CHASSIS_YAW`，底盘模式写为 `CHASSIS_VECTOR_FOLLOW_CHASSIS_YAW`；`CHASSIS_MODE_CHANNEL` 下档且跟随通道未下档时进入 `CHASSIS_NO_FOLLOW_YAW`，底盘模式写为 `CHASSIS_VECTOR_NO_FOLLOW_YAW`；`CHASSIS_MODE_CHANNEL` 上档或中档进入 `CHASSIS_NO_MOVE`；下档并按 `GIMBAL_ZERO_KEYBOARD` 也进入 `CHASSIS_NO_MOVE`。

模式切换保护：`chassis_mode_change_control_transit()` 在 `User/chassis/Mecanum_chassis.c:124-162` 只在模式变化时处理状态量；进入 `CHASSIS_VECTOR_FOLLOW_GIMBAL_YAW` 时把 `chassis_relative_angle_set` 置 `0.0f`；进入 `CHASSIS_VECTOR_FOLLOW_CHASSIS_YAW` 时把 `chassis_yaw_set` 置为当前 `chassis_yaw`，并清空底盘 yaw 角度 PID；进入 `CHASSIS_VECTOR_NO_FOLLOW_YAW` 时把 `chassis_yaw_set` 置为当前 `chassis_yaw`。该初始化使角度闭环从当前姿态起算，避免切换瞬间产生历史积分输出。

反馈更新链路：`chassis_feedback_update()` 在 `User/chassis/Mecanum_chassis.c:174-206` 把四个 3508 转速 `speed_rpm` 乘 `CHASSIS_MOTOR_RPM_TO_VECTOR_SEN = 0.000415809748903494517209f` 得到轮端线速度；底盘速度由四轮速度反解：`vx = (-v0 + v1 + v2 - v3) * 0.25f`，`vy = (-v0 - v1 + v2 + v3) * 0.25f`，`wz = (-v0 - v1 - v2 - v3) * 0.25f / MOTOR_DISTANCE_TO_CENTER`；当前工程按底盘有陀螺仪处理，`chassis_yaw/pitch/roll` 直接取 `INS` 欧拉角并用 `rad_format()` 规整到 `[-PI, PI]`。

平移设定链路：`chassis_rc_to_control_vector()` 在 `User/APP/chassis_behaviour.c:238-308` 先用 `rc_deadband_limit()` 处理 `CHASSIS_X_CHANNEL` 和 `CHASSIS_Y_CHANNEL`，再得到 `vx_set_channel = -vx_channel * 0.003f`、`vy_set_channel = -vy_channel * 0.003f`；W/S/A/D 会覆盖摇杆平移命令并使用 `vx_max_speed/vx_min_speed/vy_max_speed/vy_min_speed`；Shift 置 `slowmode = 1`，并把 `vx_set_channel` 乘 `0.2f`、`vy_set_channel` 乘 `0.25f`；随后 `first_order_filter_cali()` 对 `vx/vy` 设定做一阶滤波，滤波公式在 `User/Lib/user_lib.c:434-439`，形式为 `out = num/(num + dt) * old_out + dt/(num + dt) * input`。

底盘 yaw 闭环链路：`CHASSIS_ENGINEER_FOLLOW_CHASSIS_YAW` 的设定函数在 `User/APP/chassis_behaviour.c:638-679`，先调用 `chassis_rc_to_control_vector()` 生成平移目标，再生成 yaw 目标增量；Q 键让 `delta_angle = CHASSIS_KEY_TURN_ANGLE_RATE * 0.002f`，E 键让 `delta_angle = -CHASSIS_KEY_TURN_ANGLE_RATE * 0.002f`，`CHASSIS_KEY_TURN_ANGLE_RATE = 1.5f`；Shift 慢速模式把键盘转向速率乘 `0.08f`；无 Q/E 按键时，`CHASSIS_WZ_CHANNEL` 经死区处理后得到 `delta_angle = -wz_processed * CHASSIS_ANGLE_Z_RC_SEN`；`chassis_yaw_set = rad_format(chassis_yaw_set + delta_angle)`，并输出到 `angle_set`。

底盘 yaw 闭环执行链路：`chassis_set_contorl()` 在 `User/chassis/Mecanum_chassis.c:218-298` 调用 `chassis_behaviour_control_set()` 得到 `vx_set`、`vy_set`、`chassis_angle_set`；进入 `CHASSIS_VECTOR_FOLLOW_CHASSIS_YAW` 时，`chassis_yaw_set = rad_format(chassis_angle_set)`，`delat_angle = rad_format(chassis_yaw_set - chassis_yaw)`，误差绝对值小于 `CHASSIS_YAW_DEAD_BAND = 0.04f` rad 时置零，随后 `wz_set = PID_Calc(&chassis_angle_pid, delat_angle, 0.0f)`，`vx/vy` 通过 `fp32_constrain()` 限幅到 `[-1.0f, 1.0f]`。

保留的云台相对 yaw 跟随链路：`CHASSIS_INFANTRY_FOLLOW_GIMBAL_YAW` 的行为函数在 `User/APP/chassis_behaviour.c:547-617`，当前模式选择代码中该入口处于保留状态；进入该模式后，`chassis_set_contorl()` 在 `User/chassis/Mecanum_chassis.c:233-252` 用 `chassis_yaw_motor->relative_angle` 旋转 `vx/vy` 方向，使平移输入跟随云台坐标，再令 `chassis_relative_angle_set = rad_format(yaw_motor_relative_angle - PI / 3)`，并用 `wz_set = -PID_Calc(&chassis_angle_pid, chassis_yaw_motor->relative_angle, chassis_relative_angle_set)` 生成底盘自转目标。

无 yaw 闭环旋转链路：`CHASSIS_NO_FOLLOW_YAW` 的行为函数在 `User/APP/chassis_behaviour.c:700-727`，`CHASSIS_WZ_CHANNEL` 经死区后直接乘 `CHASSIS_WZ_RC_SEN = 0.004f` 得到 `wz_set_channel`；Q 键写 `-CHASSIS_WZ_MAX_SPEED`，E 键写 `CHASSIS_WZ_MAX_SPEED`，`CHASSIS_WZ_MAX_SPEED = 2.5f`；Shift 慢速模式把 `wz_set_channel` 乘 `0.3f`；`chassis_set_contorl()` 在 `User/chassis/Mecanum_chassis.c:272-280` 把 `chassis_angle_set` 直接写入 `wz_set`。

急停减速输入链路：`chassis_rc_to_control_vector()` 在 `User/APP/chassis_behaviour.c:292-306` 每周期先计算一阶滤波输出，再检查当前 `vx_set_channel` 与 `vy_set_channel`；当 `vx_set_channel` 落入 `±(CHASSIS_RC_DEADLINE * CHASSIS_VX_RC_SEN)`，即 `±0.075 m/s` 范围时，直接把 `chassis_cmd_slow_set_vx.out` 置 `0.0f`；当 `vy_set_channel` 落入 `±0.075 m/s` 范围时，直接把 `chassis_cmd_slow_set_vy.out` 置 `0.0f`。该链路形成平移命令的急停：松开摇杆或按键后，目标速度在同一控制周期内清零，随后四轮速度环把轮速目标拉到零。

急停模式链路：`chassis_behaviour_mode_set()` 在 `User/APP/chassis_behaviour.c:342-356` 把模式通道上档、中档、或下档加 `GIMBAL_ZERO_KEYBOARD` 映射为 `CHASSIS_NO_MOVE`；`chassis_no_move_control()` 在 `User/APP/chassis_behaviour.c:517-526` 把 `vx_set/vy_set/wz_set` 全部置零；`CHASSIS_NO_MOVE` 再映射到底盘模式 `CHASSIS_VECTOR_NO_FOLLOW_YAW`，于是后续轮速分解得到四轮零目标，四个电机速度环进入零速控制。

急停积分清理链路：`chassis_control_loop()` 在 `User/chassis/Mecanum_chassis.c:340-392` 先读取遥控 `x/y/wz` 三个通道，三个通道绝对值均不超过 `CHASSIS_RC_DEADLINE = 25` 时 `rc_all_zero = 1`；同时检查 `vx_set/vy_set/wz_set` 的绝对值均小于 `0.01f` 时 `set_speed_all_zero = 1`；两个条件连续成立超过 3 个控制周期后，四个 `motor_speed_pid` 执行 `PID_clear()`，随后清零计数器。控制周期为 2 ms，因此该保护在零输入保持约 8 ms 后清理轮速环积分。

麦轮分解链路：`chassis_vector_to_mecanum_wheel_speed()` 在 `User/chassis/Mecanum_chassis.c:318-327` 把 `vx_set/vy_set/wz_set` 分解为四个轮速目标：`wheel0 = -vx - vy + (CHASSIS_WZ_SET_SCALE - 1) * R * wz`，`wheel1 = vx - vy + (CHASSIS_WZ_SET_SCALE - 1) * R * wz`，`wheel2 = vx + vy + (-CHASSIS_WZ_SET_SCALE - 1) * R * wz`，`wheel3 = -vx + vy + (-CHASSIS_WZ_SET_SCALE - 1) * R * wz`；其中 `R = MOTOR_DISTANCE_TO_CENTER = 0.308904f`，`CHASSIS_WZ_SET_SCALE = 0.1f`。

轮速闭环链路：`chassis_control_loop()` 在 `User/chassis/Mecanum_chassis.c:393-449` 调用麦轮分解后，`CHASSIS_VECTOR_RAW` 模式直接把 `wheel_speed` 转为 `give_current`；闭环模式先把四轮 `speed_set` 写入 `motor_chassis[i].speed_set`，再用 `MAX_WHEEL_SPEED = 4.0f` 做等比例限幅，随后四个轮速 PID 以实际轮速 `motor_chassis[i].speed` 和目标轮速 `speed_set` 计算输出；`chassis_power_control()` 执行功率处理，最后把四个 PID 输出写入 `give_current`。

CAN 输出链路：`chassis_send_cmd()` 在 `User/chassis/Mecanum_chassis.c:451-462` 调用 `CAN_cmd_chassis()`；`CAN_cmd_chassis()` 在 `User/Bsp/can_bsp.c:318-329` 把四个 `int16_t` 电流拆成 8 字节，使用 `CHASSIS_CAN` 与 `CAN_3508_ALL_ID` 发送到底盘 3508 电机组。

对照另一个工程时优先核对这些锚点：`robot_param.h` 的 `ROBOT_CHASSIS/ROBOT_TYPE/ROBOT_BOARD`，`Engineer.h` 中通道和 PID 参数，`chassis_task()` 周期与调用顺序，`chassis_behaviour_mode_set()` 的模式入口，`chassis_engineer_follow_chassis_yaw_control()` 的 `chassis_yaw_set` 累加方式，`chassis_set_contorl()` 中 `CHASSIS_VECTOR_FOLLOW_CHASSIS_YAW` 的误差与 PID 方向，`chassis_rc_to_control_vector()` 的急停强制清零，`chassis_control_loop()` 的三周期 PID 清理，`chassis_vector_to_mecanum_wheel_speed()` 的四轮符号和 `CHASSIS_WZ_SET_SCALE`。
