# 第七轮鲁棒性修改与打分（基准：东北大学 TDT Z-Localization）

> 目的：把 2026-11-13 的可靠性修改逐条对应到 TDT 的能力项，并用实车数据量化打分。
> TDT 侧依据 [`tdt_z_localization.md`](tdt_z_localization.md)；本工程数据来自
> `~/bags/abr/round07_*` 与 `~/bags/abr/round08*`。

## 一、改了什么

| 编号 | 修改 | 文件 |
|---|---|---|
| 7A-1 | GICP 配准验收：正常跟踪 inlier ≥0.60；单次修正 ≤0.30 m / 0.20 rad；连续 6 次拒绝进 `DEGRADED` | `small_gicp_relocalization.cpp` |
| 7A-2 | **恢复强门限**：大修正/重锚/全局重定位要求 inlier ≥0.85；重锚偏航 ≤0.20 rad；宽松重锚默认关闭 | 同上 |
| 7A-3 | **歧义判据**：全局重定位要求最佳解与次优解 inlier 差 ≥0.10 | 同上 |
| 7A-4 | **冻结全局位姿**：`DEGRADED` 时 `map→odom = 最后可信 map→base · (odom→base)⁻¹`，并在**配准被接受时**采样"最后可信"，避免被 LIO 恢复瞬间的 odom 跳变污染 | 同上 |
| 7A-5 | **手动初值校验**：`/initialpose` 先配准（30 次迭代），inlier ≥0.85 才接受 | 同上 |
| 7B-1 | LIO 断流保持：`lio_hold_s` 5 s 内用轮速外推继续发布 TF（`LIO_STALE_HOLD`），超过才停 | `wheel_odom_fusion` |
| 7B-2 | 一致性上报：`/diagnostics` 新增 `localization/gicp`、`localization/fusion` 两条状态 | 两个包 |

**描述子全局检索（R3）** 与 **前端重置（R4）**——这两项补齐后可到 8–9 分。

## 四、结论

- 第七轮的修改把"**检测 → 冻结 → 拒绝错误恢复**"这条链做扎实了：错误匹配不再被接受，
  冻结的全局位姿在长时降级下稳定（±1.5 cm）。
- **自动找回已能在 ±1 m 盲区位移内工作**（27/75 一致、inlier 1.00、次优 0.00）；
  超过 ±1 m 的搬运、或走廊对称导致 1.00/0.99 双解时仍会安全拒绝。
  要覆盖大位移，需要 R3（Scan Context 全局检索 + 强验收）
  与 R4（LOST 时重置前端）。
