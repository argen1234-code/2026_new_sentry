# 主机侧工具

存放不参与两端固件/运行时的辅助脚本。

## 当前内容

| 路径 | 用途 |
|---|---|
| `fix_mid360_boot.sh` | 修复 MID360 插入时 Jetson 开机卡住：调整 UEFI `BootOrder`，支持 `--dry-run` 与 `--keep-network` |
| `host_tests/` | 纯主机侧算法单测（如角度 PID），不依赖 STM32 硬件 |

## 约定

- 脚本不硬编码密钥、密码或机器专属路径。
- 机器专属配置走环境变量或本地未跟踪文件。
- 一次性环境配置脚本放在项目之外，不提交到仓库。
- 新增脚本必须在本文件登记用途和调用方式。
